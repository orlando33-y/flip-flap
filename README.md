# FLIP FLAP

Paj sa a montre afich fèt FLIP FLAP la epi li fèt pou GitHub Pages.

## Pibliye sou GitHub Pages

1. Mete fichye pwojè sa yo nan depo piblik `flip-flap` sou GitHub.
2. Nan depo a, ale nan **Settings → Pages**.
3. Chwazi **Deploy from a branch**, branch `main`, epi folder `/ (root)`.
4. Apre GitHub fin pibliye paj la, li pral disponib nan:
   <https://orlando33-y.github.io/flip-flap/>

QR code la nan `flip-flap-qr.png`. Li louvri afich la dirèkteman nan:
<https://orlando33-y.github.io/flip-flap/afich-flip-flap.jpg>
